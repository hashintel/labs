Under clocks, each transition owns a clock armed with an exponential delay at its rate. Time flows until a clock reaches 0; the transition fires and the clock re-arms.

The compiler writes this in Zeroth's SPN theory: a clock `clk_T` and an event `ev_T` per transition, a Nat per place. `Transition_Birth` fires at 0 and re-arms:

```python
fires_Birth = clk_Birth == 0
return ite(fires_Birth, exp(2.0), clk_Birth), ite(fires_Birth, ~ev_Birth, None)
```

Its `flow` runs the clock down against the time `t`. Past 0 it has no value, which stops time, and the event's flow `0` keeps the event still:

```python
return ite(clk_Birth >= 0, -1 * d(t), None), 0
```

`Death` needs a token, so its clock runs only while `Population` holds one. `Place_Population` counts the events with `fired`, and `compose` hides the clocks.
