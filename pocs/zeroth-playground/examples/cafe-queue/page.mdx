`BeginService` needs a customer in `Waiting` and a free member of staff in `FreeStaff`. Under clocks the compiler must decide what an empty input place does to the clock.

The transition decides. `fires_BeginService` keeps both tests:

```python
fires_BeginService = (clk_BeginService == 0) & (Waiting != 0) & (FreeStaff != 0)
```

The clock runs down only while both places hold a token, and pauses otherwise:

```python
return ite(clk_BeginService >= 0, ite((Waiting != 0) & (FreeStaff != 0), -1 * d(t), 0 * d(t)), None), 0
```

Zeroth's own `birth_death.py` lets the places decide instead. The clock always runs, and at expiry each input place gives a token if it has one. With one input place, as for `Death` on *Rates as clocks*, the two rules agree, since an exponential delay has no memory. With two they do not: `BeginService` could take a customer from `Waiting` while `FreeStaff` is empty.
