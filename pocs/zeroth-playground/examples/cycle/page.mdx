One step of a plain net fires every enabled transition once, in record order. A firing takes its input tokens at once, and its output tokens land at the end of the step, so no token is produced and taken in the same step.

<Figure caption="One step from A 1, B 0. Go fires: it takes the token from A at once, and the token lands in B at the end of the step. Back waits, because B was empty when Back was tested.">

</Figure>

The compiler writes the step as one class, `Cycle`, with an Int per place. Its `next` method is one step of the net:

```python
fire_Go = A >= 1
A = ite(fire_Go, A - 1, A)
fire_Back = B >= 1
B = ite(fire_Back, B - 1, B)
A = ite(fire_Back, A + 1, A)
B = ite(fire_Go, B + 1, B)
```

The first four lines test and take in record order. The last two land the produced tokens. Every later example compiles this step.

**Shape** on modular splits the same step into one module per transition and one per place, joined by `compose`. `Transition_Go` writes the Bool `fire_Go` as `A >= 1`. `Place_A` applies every firing that moves `A`:

```python
A = ite(X(fire_Go), A - 1, A)
A = ite(X(fire_Back), A + 1, A)
```

`X(fire_Go)` reads the value `fire_Go` takes in this step, so `Place_A` waits for `Transition_Go`. In Zeroth a variable has one writer, so each place gets a module of its own. The plain and coin examples after this one open in this shape.
