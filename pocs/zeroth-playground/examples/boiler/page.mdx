A token can carry a real attribute that follows a differential equation. `Tank` holds one `Vessel` token whose `level` $\ell$ follows $\dot{\ell} = 0.5\,(10 - \ell)$, and `Alarm` reads the tank through a read arc once the level reaches 8.

### Refused here

The equation and the guard are code strings, and the playground ships no code parser. So the compiler refuses the net with `code-not-parsed`, once per code string.

With a parser, the monolithic step takes one Euler step of **Time step**, 0.25 here, for each token before the sweep:

```python
Tank_0_level = ite(Tank_0_present, Tank_0_level + 0.125 * (10.0 - Tank_0_level), Tank_0_level)
```

The read arc becomes a test that takes no token:

```python
fire_Alarm = Tank_0_present & (Tank_0_level >= 8.0)
```

**Shape** on modular refuses the net earlier, with `modular-coloured-not-lowered`, before it reads any code.
