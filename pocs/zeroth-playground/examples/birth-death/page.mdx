A transition at rate $\lambda$ fires within a step of length $\Delta t$ with probability $1 - e^{-\lambda \Delta t}$. The compiler makes that a coin: a draw `u_T` each step, tested against a threshold fixed at compile time.

`Birth` at rate 2, over a step of 0.5, fires when its draw reaches $e^{-1} \approx 0.37$, so in about 63% of steps:

```python
return X(u_Birth) >= 0.36787944117144233
```

`Death` also needs a token, so it tests `Population >= 1.0` beside its draw. The draws are Reals, so the places are Reals too, in the theory LRA.

### Options

- **Time step** sets $\Delta t$, and every threshold follows.
- **Marking** on Int keeps the places Int and moves each draw into an LRA module, `Draw_Birth`, that writes the Bool the guard reads.
